# Summary of format options

- Single select — one answer; `multiSelect: false`
- Multi select — many answers; `multiSelect: true`
- Preview pane — code/mockup shown on focus; only works with single select
- Option descriptions — subtitle under each label; works on all formats
- "Other" free-text — always injected automatically by the UI
- Max 4 options — the tool hard-caps at 4, so 5 items isn't possible in one question.
- Multi-select order — the result string reflects the order items were clicked, not the order they appear in the list (you clicked Other first, then Four, Two, Three — that's what came back).
- Notes on code preview — when no notes are typed, the result just says selected preview: <preview text> with no notes field at all.
- When "No logging" (no preview) was selected, the result just says "No logging" with no selected preview: field at all — clean, nothing extra. Compare:
  - Option with preview selected → "No logging" selected preview: # nothing emitted here
  - Option without preview selected → "No logging"

# Notes
- Pretty much every question had an "other" kind-of field:
  - If a custom answer is given, use `Type something:`, otherwise use `Type something.`.
    - For a multi-select all entries are added by ` ,`, but may not be in order of the list, but in order of the user selecting it.
    - The custom one is always last, this is confirmed.
      - In **Numbers 1-4**, I typed the note first, then selected the other fields, yet the note is last.
  - If using a `preview` field, the custom answer will be `_Notes:_` vs. `_Notes: Add notes on this design._` instead of `_Type something[.:]_`.
    - You need to handle the `(notes only)` special case, where then the "answer" will be in `annotations[question].notes`.
    - If you select something, instead of the notes, you'll have `annotations[question].preview` instead.
      - Add that to the `<summary>`, btw.
- Reminder that a sub-list element of a numbered list must be indented `len(str(num)) + 2` (`2 = len(". ")`).
  - So for `>> 7. Pick a logging approach (one option has no preview):`  it's 3 spaces more, i.e. `>>    - No logging`.
  - So for `>> 10. Pick a logging approach (one option has no preview):` it's 4 spaces more, i.e. `>>     - No logging`.
