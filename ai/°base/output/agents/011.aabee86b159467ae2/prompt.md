> There's also an `ai/history/master` branch (or whatever the repo's main branch is), holding AI history after a clean variant is merged into the main branch. It becomes the base for the next unclean/history branch, while the main branch is the base for the next clean branch.
>
> `update-history-master`: creates a new base history. Commit ordering: `master` commits first (all commits from origin's current main branch), then `base` (merge commits of `base/base` into `ai/history/master`), then `history` (commits of all history branches whose clean branches were already merged into master), then `merge` (empty commits marking/referencing the last/merge commit of a clean branch that had history, coming after that history branch's rebased commits).
>
> The difficult part: after clean `master` updates, `ai/history/master` must be rebased onto it, while tracking merges of clean branches with existing history/unclean variants so those can be cherry-picked too. With this rebase-and-flatten strategy, how do we gracefully support merging `base` itself, and later updates to `base`, into it occasionally?
>
> `--force-merge=<branch>` (repeatable): force a manual history-branch merge before it's included in clean master.
>
> Rough steps: 1. checkout master 2. check master up to date, ask to pull if not (default N) 3. checkout base 4. check base up to date, ask to pull if not (default N) 5. checkout ai/history/master 6. rebase ai/history/master onto master 7. merge the most recent base/base into ai/history/master.
>
> The problem: merges don't rebase well. Proposed approach: manually rebase commit-by-commit as usual, and when a base/base merge commit is hit, instead of rebasing it, recreate it by merging the OLD merged commit of base/base freshly into ai/history/master again, reapplying the old conflict resolution once more.
>
> `rebase-branches-to-master`: rebases all three branch types onto their current masters — clean→clean-master, history→ai/history/master, unclean→the just-rebased history branch. Handle 1-2 of the three branches missing.
